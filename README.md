# xext

**x** stands for anything. **ext** stands for extension.

We extend things of all kinds, from software to hardware and whatever else sparks our curiosity. We do it for fun, to learn, experiment, and see what is possible.

## Explore

Find our software and other projects in the [xext repositories](https://github.com/orgs/xext-fun/repositories). Each project is a place to explore what it extends and how it works.

## Extend something

Want to try it yourself? Browse a project that interests you and look for its README or documentation for instructions on setting it up, using it, and extending it. As we publish new projects, their repositories will be the home for the relevant code, designs, and instructions.

There is no single way to extend everything. Pick something, make it do more, and have fun with it.
